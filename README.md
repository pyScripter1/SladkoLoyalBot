# 🧁 Sladko Loyalty Bot

Telegram-бот для системы лояльности кондитерской Sladko. Автоматизирует начисление баллов, учет покупок, поздравления с днем рождения и управление клиентской базой.

## ✨ Возможности

### Для клиентов
- 🎁 **Регистрация с бонусом** — 100 баллов при регистрации
- 💎 **Система баллов** — кешбэк 3% с каждой покупки десертов
- ☕ **Программа лояльности для кофе** — каждая 6-я чашка кофе бесплатная
- 🎂 **Поздравления с днем рождения** — автоматическое начисление 300 баллов за 7 дней до ДР
- 👤 **Управление профилем** — просмотр баланса, редактирование данных
- 📱 **Обязательная подписка на канал** — для доступа к функциям бота

### Для администраторов
- 📊 **Статистика** — общая статистика по клиентам и продажам
- 💰 **Начисление баллов** — за покупки десертов и кофе
- 💸 **Списание баллов** — оплата до 50% суммы покупки баллами
- 👥 **Поиск клиентов** — по номеру телефона
- 📢 **Рассылки** — массовые рассылки с текстом и фото
- 📥 **Экспорт данных** — выгрузка базы клиентов в Excel
- ⬇️ **Скачивание базы** — получение SQLite базы данных

## 🛠 Технологии

- **Python 3.x**
- **pyTelegramBotAPI** — работа с Telegram Bot API
- **SQLite** — база данных

- **openpyxl** — экспорт данных в Excel

## ⚙️ Настройка

### 1. Получение токена бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

### 2. Настройка конфигурации

Откройте файл `config.py` и настройте следующие параметры:

```python
# Токен бота (рекомендуется использовать переменную окружения)
BOT_TOKEN = os.getenv('BOT_TOKEN', 'ваш_токен_бота')

# Настройки лояльности
INITIAL_BONUS_POINTS = 100  # Баллы за регистрацию
DESSERT_PERCENTAGE = 3       # Процент кешбэка с покупок десертов
FREE_COFFEE_AFTER = 6        # Каждая N-я чашка кофе бесплатная

# Список администраторов (ваши Telegram ID)
ADMIN_IDS = [ваш_telegram_id]

# Настройки канала для обязательной подписки
CHANNEL_USERNAME = "@ваш_канал"
CHANNEL_URL = "https://t.me/ваш_канал"
CHANNEL_ID = ваш_channel_id  # Можно получить через @userinfobot

# Настройки поздравлений с днем рождения
BIRTHDAY_NOTIFICATION_DAYS = 7    # За сколько дней уведомлять
BIRTHDAY_NOTIFICATION_TIME = "12:00"  # Время отправки уведомлений
BIRTHDAY_BONUS_POINTS = 300       # Баллы за день рождения
```

### 3. Использование переменных окружения (рекомендуется)

Для безопасности используйте переменные окружения:

**Windows:**
```bash
set BOT_TOKEN=ваш_токен_бота
```

**Linux/Mac:**
```bash
export BOT_TOKEN=ваш_токен_бота
```

Или создайте файл `.env` (не забудьте добавить его в `.gitignore`):
```
BOT_TOKEN=ваш_токен_бота
```

## 🚀 Использование

### Запуск бота

```bash
python bot.py
```

Бот автоматически:
- Создаст базу данных в папке `data/`
- Запустит планировщик дней рождения
- Начнет принимать команды от пользователей

### Основные команды

- `/start` — начало работы с ботом (регистрация или вход)
- `/admin` — вход в режим администратора

## 👨‍💼 Администраторские функции

### Начисление баллов

1. Нажмите "📱 Начислить баллы"
2. Введите номер телефона клиента
3. Выберите тип покупки:
   - **☕ Кофе** — начисление чашки кофе (каждая 6-я бесплатная)
   - **🍰 Десерты** — начисление баллов (3% от суммы)

### Списание баллов

1. Нажмите "💸 Списать баллы"
2. Введите номер телефона клиента
3. Введите сумму покупки
4. Система автоматически рассчитает максимальное списание (50% от суммы)
5. Подтвердите операцию

### Поиск клиента

1. Нажмите "👥 Поиск клиента"
2. Введите номер телефона
3. Получите полную информацию о клиенте

### Создание рассылки

1. Нажмите "📢 Создать рассылку"
2. Выберите тип:
   - **📝 Только текст** — текстовая рассылка
   - **🖼️ С фотографией** — рассылка с изображением
3. Введите текст (поддерживается Markdown)
4. При необходимости прикрепите фото
5. Просмотрите предпросмотр
6. Отправьте всем клиентам

### Экспорт данных

- **📊 Экспорт в Excel** — выгрузка базы клиентов в Excel файл
- **⬇️ Скачать базу клиентов** — получение SQLite базы данных

## 🔧 Особенности реализации

### Нормализация номеров телефонов

Бот автоматически нормализует номера телефонов:
- Формат `89969090490` → сохраняется как `+79969090490`
- Формат `+79969090490` → сохраняется как `+79969090490`

### Система счетчика кофе

- При покупке 6-й чашки счетчик автоматически обнуляется
- Клиент получает уведомление о бесплатной чашке кофе
- При 5 чашках отображается: "Следующая чашка кофе бесплатная!"

### Автоматические поздравления

- Планировщик проверяет дни рождения каждый день в 12:00
- За 7 дней до ДР клиент получает поздравление и 300 баллов
- Уведомление отправляется только один раз в год
